Privacidad de los datos de salud

VICBANGFIT solicita permiso para leer únicamente el total de pasos registrado por Health Connect cuando el cliente activa voluntariamente esta función.

Uso de los datos

El total diario se utiliza para mostrar el progreso del cliente respecto al objetivo indicado por su entrenador. No se recopilan la ubicación, el recorrido, contactos ni otros datos de salud.

Acceso y control

Los pasos son visibles únicamente para el cliente y su entrenador vinculado. El cliente puede retirar el permiso desde los ajustes de Health Connect en cualquier momento.

Almacenamiento

VICBANGFIT guarda el total diario y la fecha de sincronización para mostrar el histórico. No vende ni utiliza estos datos con fines publicitarios.
